MUSICA DE LOGOS - CARPETAS PARA GITHUB

1. Sube los archivos de audio a las carpetas:
   inicio/              (pantalla inicial)
   juego/suave/        (preguntas 1-5)
   juego/media/        (preguntas 6-10)
   juego/intensa/      (preguntas 11-15)
   victoria/           (al ganar el concurso)

2. Abre 'catalog.json' en GitHub y agrega los nombres EXACTOS de las canciones,
   incluyendo las rutas. Ejemplo (si has subido esos archivos):

{
  "inicio": ["inicio/ambientacion.mp3"],
  "suave": ["juego/suave/calidez.mp3", "juego/suave/paz.ogg"],
  "media": ["juego/media/expectativa.mp3"],
  "intensa": ["juego/intensa/tension.mp3"],
  "victoria": ["victoria/celebracion.mp3"]
}

3. Guarda los cambios, actualiza LOGOS, activa GitHub como fuente musical.
   LOGOS elegira al azar entre las canciones de la etapa correspondiente.

4. Para escucharlas sin internet desde el primer juego sin conexion, abre
   Configuracion > DESCARGAR TODA LA MUSICA DE GITHUB (solo una vez conectado).
   Si cambias archivos, vuelve a descargar y puedes limpiar datos del sitio.

Nota: GitHub Pages es un alojamiento ESTATICO: no permite descubrir nombres
nuevos de archivos en carpetas. Por eso hay que enumerarlos en catalog.json.
Los nombres y las tildes deben coincidir exactamente. Recomendamos nombres sin
espacios ni tildes.

Puedes subir musica que tengas derecho a utilizar. Las canciones de GitHub son
accesibles para cualquiera que tenga el enlace al repositorio publico.
